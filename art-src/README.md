# Art sources

Everything behind `client/assets/` is generated by scripts, so changes are made in code and re-run
rather than by hand-editing the `.blend`.

| Path | What |
| --- | --- |
| `tools/make_textures.py` | Paints the tiling source textures (numpy brush strokes) into `source/textures/` |
| `tools/build_assets.py` | Models all assets, bakes painted light, exports `.glb` into `client/assets/`, renders `previews/` |
| `tools/preview_glb.py` | Quick render of already exported `.glb` files |
| `source/textures/` | Tiling hand-painted source textures |
| `source/blend/openrail_assets.blend` | All assets as a small diorama (output of the build, for inspection) |
| `previews/` | Renders of each asset |

## Regenerating (Blender 5.2)

```powershell
$b = "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe"
& $b -b --factory-startup --python art-src/tools/make_textures.py
& $b -b --factory-startup --python art-src/tools/build_assets.py            # full quality
& $b -b --factory-startup --python art-src/tools/build_assets.py -- --fast  # quarter-res bakes
```

`-- --no-render` skips the previews. Baking uses Cycles on the GPU when one is available
(about 6 minutes on an RTX 3070 at full quality). Set `OPENRAIL_EXPORT` to export elsewhere.

## How the look is made

The style follows [docs/art-style.md](../docs/art-style.md): Arcane's way of painting, not its
architecture.

1. Parts are box-mapped with calm, low-contrast painted textures.
2. Each mesh gets its own UV unwrap, and Cycles bakes texture × painted light into one image:
   top-lit, cool blue shadows, ambient occlusion and warm highlights on bevelled edges.
3. A Kuwahara filter turns the bake into flat, brush-like patches.
4. Each mesh keeps one material with that albedo, plus emissive lamps.
